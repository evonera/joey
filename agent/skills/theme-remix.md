Use this skill when the user provides a link, screenshot, or scout alert from a competitor/reference theme page (e.g. Pubity, Overheard, MorningBrew, etc.) and asks to "remix", "adapt", or "make our version."

## Guiding Principles

1. **Never Plagiarize**: Steal the _structure, pacing, and emotional hook_, never the exact copy, artwork, or punchlines.
2. **Translate into Brand Identity**: Adapt the topic to the workspace's target audience, brand voice, and niche.
3. **Enhance Format Quality**: If the original was a messy tweet screenshot, elevate it into a clean Theme Studio graphic, split-screen video reel, or structured carousel.

## Step-by-Step Remix Process

1. **Deconstruct the Core Spark**:
   - What is the underlying premise? (e.g. Relatable workplace frustration, counter-intuitive tech benchmark, breaking news reaction).
   - Why did it get high engagement? (Controversy, humor, utility, validation).
2. **Re-frame for Our Audience**:
   - Swap the context to our domain while keeping the tension or humor.
3. **Map to Theme Studio Templates**:
   - Format A: Hero Meme Card (`static-card` with high-contrast text and reaction image)
   - Format B: Tweet/Thread Quote (`tweet-card` format)
   - Format C: Short-form Motion Reel (`video-reel` with bold animated captions)
4. **Draft and Offer Action**:
   - Produce the ready-to-publish copy.
   - Offer to queue it into Theme Studio or create an approval draft using `draft_post`.
